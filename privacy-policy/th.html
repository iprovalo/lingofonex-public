นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: May 17, 2026

นโยบายความเป็นส่วนตัวนี้อธิบายประเภทของข้อมูลส่วนบุคคล (ตามที่นิยามไว้ด้านล่าง) ที่ Lingofonex อาจเก็บรวบรวมจากผู้ใช้ทั้งหมด หรือที่ท่านอาจให้แก่เราเมื่อเข้าถึงและใช้งานเว็บไซต์ของเราและแอปพลิเคชันการแปลภาษาบนมือถือระบบ iOS หรือ Android ของเรา (เรียกรวมกันว่า "Application") ซึ่งอาจมีการเผยแพร่ภายใต้ชื่อ แบรนด์ หรือรายการในหน้าร้านที่แตกต่างกันไปขึ้นอยู่กับแพลตฟอร์มหรือตลาด รวมถึง Pakt Translator และ Lingofonex นโยบายความเป็นส่วนตัวนี้ยังอธิบายถึงนโยบายและขั้นตอนของเราในการเก็บรวบรวม ใช้ บำรุงรักษา คุ้มครอง และเปิดเผยข้อมูลส่วนบุคคลของท่านเมื่อท่านเข้าถึงและใช้งาน Application และแจ้งให้ท่านทราบเกี่ยวกับสิทธิความเป็นส่วนตัวของท่านและทางเลือกที่ท่านมีในส่วนที่เกี่ยวกับข้อมูลส่วนบุคคลของท่าน "Personal information" หมายถึงข้อมูลใด ๆ ที่ระบุตัวตน เกี่ยวข้องกับ หรือสามารถเชื่อมโยงได้อย่างสมเหตุสมผลกับท่านหรือครัวเรือนของท่าน ตัวอย่างเช่น อาจรวมถึงชื่อของท่าน ที่อยู่อีเมล บันทึกผลิตภัณฑ์ที่ท่านได้ซื้อ ประวัติการเรียกดูอินเทอร์เน็ต ข้อมูลตำแหน่งทางภูมิศาสตร์ และการอนุมานจากข้อมูลส่วนบุคคลอื่น ๆ ที่อาจสร้างโปรไฟล์ของความชอบและลักษณะเฉพาะของท่าน

โปรดอ่านนโยบายความเป็นส่วนตัวนี้อย่างละเอียดก่อนเข้าถึงและใช้งาน Application เพื่อทำความเข้าใจนโยบายและขั้นตอนของเราเกี่ยวกับข้อมูลส่วนบุคคลของท่านและวิธีที่เราจะปฏิบัติต่อข้อมูลดังกล่าว

คำที่ขึ้นต้นด้วยตัวพิมพ์ใหญ่ซึ่งมิได้นิยามไว้เป็นอย่างอื่นด้านล่างให้มีความหมายตามที่กำหนดไว้ในข้อตกลงสิทธิ์การใช้งานสำหรับผู้ใช้ปลายทางของเรา

การยอมรับ

การที่ท่านเข้าถึงและใช้งาน Application ของเรา ถือว่าท่านตกลงยินยอมให้มีการเก็บรวบรวมและใช้ข้อมูลส่วนบุคคลของท่านตามนโยบายความเป็นส่วนตัวนี้ หากท่านไม่เห็นด้วยกับนโยบายของเรา โปรดอย่าดาวน์โหลด เข้าถึง หรือใช้งาน Application

การปรับปรุงแก้ไข

เราขอสงวนสิทธิ์ในการแก้ไขนโยบายความเป็นส่วนตัวนี้ได้ตลอดเวลาโดยการเผยแพร่นโยบายความเป็นส่วนตัวที่อัปเดตแล้วบน Application หากเรามีการเปลี่ยนแปลง เราจะแจ้งให้ท่านทราบโดยการแก้ไขวันที่ที่ด้านบนของนโยบาย หากเรามีการเปลี่ยนแปลงในสาระสำคัญใด ๆ เราอาจแจ้งให้ท่านทราบบน Application ท่านมีหน้าที่รับผิดชอบในการทบทวนนโยบายความเป็นส่วนตัวนี้อย่างสม่ำเสมอ และการที่ท่านใช้งาน Application ต่อไปหลังจากที่เรามีการเปลี่ยนแปลงถือเป็นการยอมรับนโยบายความเป็นส่วนตัวที่อัปเดตแล้วของท่าน หากการแก้ไขใด ๆ เป็นที่ยอมรับไม่ได้สำหรับท่าน ท่านจะต้องหยุดใช้งาน Application หากท่านมีคำถามใด ๆ เกี่ยวกับนโยบายความเป็นส่วนตัวนี้ หรือหากท่านประสงค์จะใช้สิทธิใด ๆ ของท่านภายใต้นโยบายความเป็นส่วนตัวนี้ ท่านสามารถติดต่อเราได้ที่ info[at]lingofonex.com

การบังคับใช้

Application ได้รับการออกแบบด้วยแนวทางที่ให้ความสำคัญกับความเป็นส่วนตัวเป็นอันดับแรกและประมวลผลบนอุปกรณ์ ฟังก์ชันหลัก ซึ่งรวมถึงการรู้จำเสียงพูด การแปลภาษา การรู้จำข้อความ การแปลผ่านกล้อง และการสังเคราะห์เสียงพูด โดยทั่วไปจะประมวลผลภายในเครื่องบนอุปกรณ์ของท่านเพื่อลดการส่งและการจัดเก็บเนื้อหาของผู้ใช้ อย่างไรก็ตาม คุณลักษณะบางอย่างของ Application ที่เกี่ยวกับการปฏิบัติงาน การสร้างรายได้ ที่เกี่ยวกับแอปพลิเคชัน ที่เกี่ยวกับการสนับสนุน ที่เกี่ยวกับการวิเคราะห์ ที่เกี่ยวกับความปลอดภัย หรือที่เกี่ยวกับการโฆษณา อาจเกี่ยวข้องกับการส่ง การประมวลผล หรือการจัดเก็บข้อมูลทางเทคนิคที่จำกัด ข้อมูลอุปกรณ์ ข้อมูลการใช้งาน ข้อมูลการวินิจฉัย ข้อมูลสถานะการสมัครสมาชิก ตัวระบุการโฆษณา หรือข้อมูลที่เกี่ยวข้อง โดยเราหรือผู้ให้บริการบุคคลที่สามของเรา ตามที่อธิบายเพิ่มเติมในนโยบายความเป็นส่วนตัวนี้

1. ข้อมูลส่วนบุคคลที่เราเก็บรวบรวมเกี่ยวกับท่าน

เราอาจเก็บรวบรวมข้อมูลส่วนบุคคลจากหรือเกี่ยวกับท่านได้หลากหลายวิธี รวมถึง: (ก) โดยตรงจากท่าน; (ข) โดยอัตโนมัติผ่านการเข้าถึงหรือการใช้งาน Application ของท่าน; และ (ค) จากบุคคลที่สาม ผู้ให้บริการ ผู้จัดจำหน่ายแอป พันธมิตรทางธุรกิจ หรือการเชื่อมต่อที่เกี่ยวข้องกับ Application

หมวดหมู่และประเภทของข้อมูลส่วนบุคคลที่เราเก็บรวบรวมอาจแตกต่างกันไปขึ้นอยู่กับวิธีที่ท่านเข้าถึงและใช้งาน Application รวมถึงคุณลักษณะที่ท่านใช้ การตั้งค่าอุปกรณ์และ Application ของท่าน ไม่ว่าท่านจะใช้การเข้าถึงแบบฟรีหรือคุณลักษณะแบบชำระเงิน และการเชื่อมต่อหรือบริการของบุคคลที่สามที่เปิดใช้งานภายใน Application

ข้อมูลส่วนบุคคลที่เราเก็บรวบรวมโดยตรงจากท่าน

ขณะที่ท่านใช้งาน Application ท่านอาจให้ข้อมูลส่วนบุคคลบางอย่างแก่เราโดยสมัครใจซึ่งจำเป็นต่อการเข้าถึงคุณลักษณะของ Application การสื่อสารกับเรา การขอความช่วยเหลือ การส่งความคิดเห็น หรือการโต้ตอบกับเราในรูปแบบอื่น หมวดหมู่ของข้อมูลส่วนบุคคลที่เราอาจเก็บรวบรวมโดยตรงจากท่านรวมถึง:

  • ข้อมูลการติดต่อ ชื่อ ที่อยู่อีเมล ที่อยู่ไปรษณีย์ หมายเลขโทรศัพท์ หรือข้อมูลการติดต่ออื่น ๆ ที่ท่านเลือกที่จะให้

  • ข้อมูลธุรกิจ ชื่อธุรกิจ เว็บไซต์ ข้อมูลการติดต่อทางธุรกิจ หรือรายละเอียดทางธุรกิจที่เกี่ยวข้องที่ท่านให้โดยสมัครใจ

  • สิทธิ์การเข้าถึงอุปกรณ์และการเข้าถึงอุปกรณ์ภายในเครื่อง Application อาจเข้าถึงคุณลักษณะหรือข้อมูลของอุปกรณ์ ขึ้นอยู่กับคุณลักษณะที่ท่านใช้และสิทธิ์ที่ท่านให้ เช่น กล้อง ไมโครโฟน คลังภาพ ฟังก์ชันการรู้จำเสียงพูด หรือพื้นที่จัดเก็บภายในเครื่องของท่าน การประมวลผลที่เกี่ยวกับการแปลหลักโดยทั่วไปจะดำเนินการภายในเครื่องบนอุปกรณ์ของท่าน และโดยทั่วไปเราไม่ได้รับหรือจัดเก็บเนื้อหาของผู้ใช้ที่เกี่ยวข้อง เว้นแต่ท่านจะให้ข้อมูลดังกล่าวแก่เราแยกต่างหาก เช่น ผ่านการขอความช่วยเหลือหรือการส่งความคิดเห็น

  • ข้อมูลการสื่อสารและการสนับสนุน ข้อมูลที่อยู่ในการสื่อสารที่ท่านส่งถึงเรา รวมถึงอีเมล การขอความช่วยเหลือ การส่งความคิดเห็น การสอบถามฝ่ายบริการลูกค้า สิ่งที่แนบมา ภาพหน้าจอ หรือข้อมูลอื่น ๆ ที่ท่านเลือกที่จะให้

  • คำรับรองและการส่งข้อมูลสู่สาธารณะ คำรับรอง รีวิว ความคิดเห็น การตอบแบบสำรวจ หรือเนื้อหาอื่น ๆ ที่ท่านส่งให้เราโดยสมัครใจหรืออนุญาตให้เราเผยแพร่

ข้อมูลส่วนบุคคลที่อ่อนไหว

เราไม่ได้ร้องขอหรือกำหนดให้ท่านต้องให้ข้อมูลส่วนบุคคลที่อ่อนไหวโดยเจตนา รวมถึงแต่ไม่จำกัดเพียง ข้อมูลที่เกี่ยวกับข้อมูลรับรองบัญชีทางการเงิน หมายเลขประจำตัวที่ออกโดยรัฐบาล ข้อมูลตำแหน่งทางภูมิศาสตร์ที่แม่นยำ ข้อมูลสุขภาพ ข้อมูลชีวมิติ เชื้อชาติหรือชาติพันธุ์ ความเชื่อทางศาสนา รสนิยมทางเพศ สถานะการเป็นพลเมืองหรือการเข้าเมือง การเป็นสมาชิกสหภาพแรงงาน ประวัติอาชญากรรม หรือข้อมูลอื่น ๆ ที่ถือว่าเป็นข้อมูลที่อ่อนไหวภายใต้กฎหมายที่ใช้บังคับ ท่านไม่ควรส่ง อัปโหลด ส่งผ่าน แบ่งปัน หรือให้ข้อมูลส่วนบุคคลที่อ่อนไหวผ่าน Application หรือในการสื่อสารกับเรา

เราไม่สามารถควบคุมข้อมูล เนื้อหา วัสดุ การบันทึก ภาพหน้าจอ รูปภาพ สิ่งที่แนบมา คำแปล การขอความช่วยเหลือ ความคิดเห็น หรือข้อมูลอื่น ๆ ที่ผู้ใช้เลือกที่จะส่ง อัปโหลด ส่งผ่าน แบ่งปัน หรือให้โดยสมัครใจผ่าน Application หรือในการสื่อสารกับเรา ด้วยเหตุนี้ เนื้อหาของผู้ใช้หรือวัสดุที่เกี่ยวกับการสนับสนุนบางอย่างอาจมีข้อมูลส่วนบุคคลที่อ่อนไหว หากและในขอบเขตที่เราเข้าถึงข้อมูลส่วนบุคคลที่อ่อนไหวซึ่งไม่จำเป็นอย่างสมเหตุสมผลสำหรับการดำเนินงาน การสนับสนุน ความปลอดภัย หรือการปฏิบัติตามกฎหมายของ Application เราจะใช้ความพยายามที่สมเหตุสมผลในเชิงพาณิชย์เพื่อลบข้อมูลดังกล่าวตามกฎหมายที่ใช้บังคับและแนวปฏิบัติในการเก็บรักษาข้อมูลของเรา

ข้อมูลที่เราเก็บรวบรวมจากท่านโดยอัตโนมัติ

เมื่อท่านเข้าถึงหรือใช้งาน Application ผู้ให้บริการของเราและเราอาจเก็บรวบรวมข้อมูลทางเทคนิค อุปกรณ์ การใช้งาน การวิเคราะห์ และการวินิจฉัยบางอย่างที่เกี่ยวกับการใช้งาน Application ของท่านโดยอัตโนมัติ ข้อมูลนี้อาจรวมถึง:

  • ข้อมูลอุปกรณ์ รวมถึงประเภทอุปกรณ์ รุ่นฮาร์ดแวร์ ระบบปฏิบัติการ เวอร์ชันระบบปฏิบัติการ ภาษาของอุปกรณ์ ผู้ให้บริการเครือข่ายมือถือ ประเภทเบราว์เซอร์ เวอร์ชันแอปพลิเคชัน และข้อมูลการกำหนดค่าทางเทคนิคที่เกี่ยวข้อง

  • ข้อมูลเครือข่ายและการเชื่อมต่อ รวมถึงที่อยู่ IP ภูมิภาคทางภูมิศาสตร์โดยประมาณที่ได้มาจากที่อยู่ IP ประเภทเครือข่าย และสถานะการเชื่อมต่อ

  • ข้อมูลการใช้งานและการโต้ตอบ รวมถึงคุณลักษณะที่เข้าถึง หน้าจอที่ดู การกระทำที่ดำเนินการภายใน Application ระยะเวลาเซสชัน ความถี่ในการใช้งาน เหตุการณ์ขัดข้อง ข้อมูลประสิทธิภาพ และข้อมูลการวินิจฉัยหรือการวิเคราะห์อื่น ๆ

  • ตัวระบุอุปกรณ์มือถือและตัวระบุทางเทคนิค รวมถึงตัวระบุการโฆษณา ตัวระบุการติดตั้ง ตัวระบุอุปกรณ์ หรือตัวระบุอื่น ๆ ที่เกี่ยวข้องกับอุปกรณ์ของท่านหรือการใช้งาน Application

  • บันทึก ข้อมูลทางไกล รายงานการขัดข้อง และข้อมูลการแก้ไขข้อบกพร่องที่สร้างขึ้นเกี่ยวกับการใช้งาน Application ของท่าน และ

  • ข้อมูลที่เกี่ยวกับการดาวน์โหลด การอัปเดต ความพร้อมใช้งานของคุณลักษณะ สถานะการสมัครสมาชิก การโต้ตอบกับโฆษณา หรือการเชื่อมต่อที่เกี่ยวข้องกับ Application

ข้อมูลที่เก็บรวบรวมโดยอัตโนมัติบางอย่างอาจถือเป็นข้อมูลส่วนบุคคลภายใต้กฎหมายที่ใช้บังคับ รวมถึงที่อยู่ IP ตัวระบุอุปกรณ์ ตัวระบุการโฆษณา และข้อมูลทางเทคนิคที่คล้ายคลึงกัน ผู้ให้บริการของเราอาจใช้ข้อมูลที่เก็บรวบรวมโดยอัตโนมัติเพื่อดำเนินการ บำรุงรักษา วิเคราะห์ แก้ไขปัญหา รักษาความปลอดภัย สนับสนุน ปรับให้เหมาะกับบุคคล ปรับปรุง ตรวจสอบ คุ้มครอง และพัฒนา Application และฟังก์ชันที่เกี่ยวข้อง รวมถึงการวิเคราะห์ การป้องกันการฉ้อโกง การจัดการการสมัครสมาชิก การส่งโฆษณา การตรวจสอบประสิทธิภาพ และการสนับสนุนการปฏิบัติงาน

คุกกี้และเทคโนโลยีการติดตามของบุคคลที่สาม

ผู้ให้บริการบุคคลที่สามของเราอาจใช้คุกกี้ ตัวระบุอุปกรณ์ พื้นที่จัดเก็บภายในเครื่อง ชุดพัฒนาซอฟต์แวร์ (SDK) เครื่องมือวิเคราะห์ พิกเซล เว็บบีคอน และเทคโนโลยีที่คล้ายคลึงกันเพื่อเก็บรวบรวมและจัดเก็บข้อมูลทางเทคนิค การใช้งาน การวินิจฉัย และข้อมูลที่เกี่ยวกับอุปกรณ์บางอย่างที่เกี่ยวกับการใช้งาน Application ของท่าน

เทคโนโลยีเว็บไซต์

เมื่อท่านเข้าถึง Application ผู้ให้บริการของเราและเราอาจใช้คุกกี้เบราว์เซอร์ พื้นที่จัดเก็บภายในเครื่อง พื้นที่จัดเก็บเซสชัน พิกเซล หรือเทคโนโลยีเว็บที่คล้ายคลึงกันเพื่อ:

  • ดำเนินการและรักษาความปลอดภัยเว็บไซต์ของเรา

  • จดจำการตั้งค่าและการกำหนดค่า

  • ทำความเข้าใจการใช้งานและประสิทธิภาพของเว็บไซต์

  • วิเคราะห์การเข้าชมและการโต้ตอบ และ

  • ปรับปรุง Application และฟังก์ชันที่เกี่ยวข้อง

ท่านอาจสามารถควบคุมการตั้งค่าคุกกี้บางอย่างได้ผ่านการตั้งค่าเบราว์เซอร์หรือการตั้งค่าอุปกรณ์ของท่าน

เทคโนโลยีมือถือและแอปพลิเคชัน

โดยทั่วไป Application ไม่ได้ใช้คุกกี้เบราว์เซอร์แบบดั้งเดิม อย่างไรก็ตาม Application และผู้ให้บริการบุคคลที่สามของเราอาจใช้ตัวระบุอุปกรณ์ เทคโนโลยีการวิเคราะห์บนมือถือ พื้นที่จัดเก็บภายในเครื่อง SDK ตัวระบุการโฆษณา และเทคโนโลยีที่คล้ายคลึงกันเพื่อดำเนินการ บำรุงรักษา รักษาความปลอดภัย วิเคราะห์ ปรับปรุง ปรับให้เหมาะกับบุคคล สนับสนุน และตรวจสอบ Application เทคโนโลยีเหล่านี้อาจเก็บรวบรวมข้อมูล เช่น:

  • ประเภทอุปกรณ์และระบบปฏิบัติการ

  • เวอร์ชันแอปพลิเคชันและการตั้งค่าภาษา

  • กิจกรรมการใช้งานและการโต้ตอบกับคุณลักษณะ

  • รายงานการขัดข้องและข้อมูลการวินิจฉัย

  • สถานะการสมัครสมาชิกหรือการซื้อ

  • ตัวระบุการโฆษณา

  • ตัวระบุการติดตั้ง และ

  • ข้อมูลประสิทธิภาพและการวิเคราะห์

เทคโนโลยีบางอย่างอาจจำเป็นสำหรับการดำเนินงาน ความปลอดภัย ฟังก์ชันการทำงาน หรือประสิทธิภาพของ Application ในขณะที่เทคโนโลยีอื่น ๆ อาจสนับสนุนการวิเคราะห์ การโฆษณา การสร้างรายได้ การวินิจฉัย การปรับให้เหมาะกับบุคคล หรือวัตถุประสงค์ในการปฏิบัติงานที่คล้ายคลึงกัน

ความยินยอมและการควบคุม

ในกรณีที่กฎหมายที่ใช้บังคับกำหนด เราจะขอความยินยอมก่อนใช้คุกกี้หรือเทคโนโลยีการติดตามที่ไม่จำเป็น ขึ้นอยู่กับอุปกรณ์ ระบบปฏิบัติการ เบราว์เซอร์ หรือภูมิภาคของท่าน ท่านอาจสามารถจำกัดการเก็บรวบรวมข้อมูลหรือการติดตามบางอย่างได้ผ่านการตั้งค่าเบราว์เซอร์ อุปกรณ์ หรือระบบปฏิบัติการของท่าน หรือผ่านการควบคุมการโฆษณา/ความเป็นส่วนตัว

เทคโนโลยีของบุคคลที่สาม

ผู้ให้บริการด้านการวิเคราะห์ การโฆษณา การสร้างรายได้ การรายงานการขัดข้อง การจัดการการสมัครสมาชิก การกำหนดค่าระยะไกล หรือผู้ให้บริการอื่น ๆ ที่ใช้เกี่ยวกับ Application อาจใช้คุกกี้ SDK ตัวระบุอุปกรณ์ หรือเทคโนโลยีที่คล้ายคลึงกันด้วย ซึ่งอยู่ภายใต้นโยบายความเป็นส่วนตัวและข้อกำหนดของตนเอง เราไม่ควบคุมแนวปฏิบัติด้านความเป็นส่วนตัวของผู้ให้บริการบุคคลที่สาม

การวิเคราะห์เว็บไซต์

เราใช้การวิเคราะห์เว็บไซต์ที่ติดตามและรายงานการเข้าชมเว็บไซต์บนเว็บไซต์ของเรา แต่ไม่ใช่ Application ของเรา ("Website Analytics") Website Analytics เก็บรวบรวมข้อมูลเกี่ยวกับประสิทธิภาพของเว็บไซต์ของเราและวิธีที่ผู้ใช้ของเรานำทางและใช้งาน เพื่อให้เราสามารถปรับปรุงประสิทธิภาพได้ เราใช้ Website Analytics เป็นบริการติดตามของบุคคลที่สาม แต่เราไม่ได้ใช้เพื่อติดตามท่านเป็นรายบุคคลหรือเก็บรวบรวมข้อมูลส่วนบุคคลของท่าน

Website Analytics อาจเก็บรวบรวมข้อมูลที่ไม่สามารถระบุตัวบุคคลได้บางอย่างเมื่อเวลาผ่านไป เช่น ที่อยู่ IP ของท่าน ประเภทเบราว์เซอร์ ผู้ให้บริการอินเทอร์เน็ต หน้าอ้างอิงและหน้าออก การประทับเวลา และข้อมูลที่คล้ายคลึงกันเกี่ยวกับการใช้งานเว็บไซต์ของท่าน เราไม่เชื่อมโยงข้อมูลนี้กับข้อมูลส่วนบุคคลของท่านใด ๆ เช่น ชื่อบัญชีหรือที่อยู่อีเมลของท่าน

ข้อมูลส่วนบุคคลที่เราเก็บรวบรวมจากบุคคลที่สาม

เราอาจได้รับข้อมูลส่วนบุคคลหรือข้อมูลอื่น ๆ ที่เกี่ยวกับท่านจากบุคคลที่สาม รวมถึง:

  • ผู้จัดจำหน่ายแอป เช่น Apple หรือ Google

  • ผู้ให้บริการด้านการวิเคราะห์ การรายงานการขัดข้อง การโฆษณา การจัดการการสมัครสมาชิก การสร้างรายได้ หรือบริการคลาวด์

  • ผู้ให้บริการสนับสนุนลูกค้า

  • ผู้ให้บริการอุปกรณ์หรือระบบปฏิบัติการ และ

  • ผู้ให้บริการอื่น ๆ ผู้จำหน่ายในการปฏิบัติงาน หรือบุคคลที่สามที่ช่วยในการจัดหา สนับสนุน รักษาความปลอดภัย จัดจำหน่าย สร้างรายได้ หรือปรับปรุง Application

ข้อมูลที่เราอาจได้รับจากบุคคลที่สามอาจรวมถึงข้อมูลที่เกี่ยวกับบัญชี สถานะการสมัครสมาชิกหรือการซื้อ การยืนยันธุรกรรม ตัวระบุอุปกรณ์ ตัวระบุการโฆษณา ข้อมูลการวิเคราะห์ รายงานการขัดข้อง ข้อมูลทางเทคนิค ข้อมูลการวินิจฉัย ข้อมูลการใช้งาน ข้อมูลที่เกี่ยวกับการสนับสนุน หรือข้อมูลอื่น ๆ ที่จำเป็นอย่างสมเหตุสมผลในการดำเนินการหรือสนับสนุน Application

โดยทั่วไปเราไม่ได้รับเนื้อหาของผู้ใช้หรือข้อมูลการแปลจากบุคคลที่สามโดยเจตนา เว้นแต่ในกรณีที่ท่านให้โดยสมัครใจหรือตามที่อธิบายไว้เป็นอย่างอื่นในนโยบายความเป็นส่วนตัวนี้

2. วิธีที่เราใช้ข้อมูลส่วนบุคคลของท่าน

เราใช้ข้อมูลส่วนบุคคลที่ท่านให้ไว้ หรือที่เราเก็บรวบรวม:

  • เพื่อนำเสนอ Application ของเราแก่ท่าน

  • เพื่อจัดหาและบำรุงรักษาฟังก์ชันการทำงานของ Application รวมถึงการตรวจสอบการใช้งาน Application ของเรา

  • เพื่อแจ้งให้ท่านทราบเกี่ยวกับการเปลี่ยนแปลงใน Application ของเรา

  • เพื่อให้ท่านสามารถเข้าร่วมในคุณลักษณะแบบโต้ตอบของ Application ของเราเมื่อท่านเลือกที่จะทำเช่นนั้น

  • เพื่อให้การสนับสนุนลูกค้า

  • เพื่อให้ข่าวสาร ข้อเสนอพิเศษ และข้อมูลทั่วไปแก่ท่านเกี่ยวกับสินค้า บริการ และกิจกรรมอื่น ๆ ที่เราเสนอซึ่งคล้ายคลึงกับสิ่งที่ท่านได้ซื้อหรือสอบถามไปแล้ว เว้นแต่ท่านได้เลือกที่จะไม่รับข้อมูลดังกล่าว

  • เพื่อวัตถุประสงค์ทางธุรกิจภายในของเรา เช่น การวิเคราะห์ข้อมูล การตรวจสอบ และอื่น ๆ

  • เพื่อรวบรวมการวิเคราะห์หรือข้อมูลที่มีค่าเพื่อให้เราสามารถปรับปรุง Application ของเราได้

  • เพื่อปฏิบัติตามภาระผูกพันของเราและบังคับใช้สิทธิของเราที่เกิดจากสัญญาใด ๆ ที่ท่านได้ทำกับเรา

  • เพื่อตรวจสอบการใช้งาน Application ของเรา

  • เพื่อตรวจจับเหตุการณ์ด้านความปลอดภัยและป้องกันกิจกรรมที่หลอกลวง ผิดกฎหมาย หรือไม่ได้รับอนุญาต

  • เพื่อปฏิบัติตามกฎหมายที่ใช้บังคับ

  • เพื่อประเมินและ/หรือดำเนินการขายกิจการ การปรับโครงสร้าง การเลิกกิจการ การควบรวมกิจการ หรือการโอนหรือขายทรัพย์สินบางส่วนหรือทั้งหมดของเรา

  • ในวิธีอื่นใดที่เราอาจอธิบายเมื่อท่านให้ข้อมูล และ

  • เพื่อวัตถุประสงค์อื่นใดด้วยความยินยอมของท่าน

3. วิธีที่เราแบ่งปันและเปิดเผยข้อมูลส่วนบุคคลของท่าน

ในกรณีที่ได้รับอนุญาตภายใต้กฎหมายที่ใช้บังคับ เราอาจแบ่งปันข้อมูลของท่านในสถานการณ์ต่อไปนี้:

  • กับผู้ให้บริการ เราอาจแบ่งปันข้อมูลส่วนบุคคลของท่านกับผู้ให้บริการ ผู้รับเหมา และบุคคลที่สามอื่น ๆ ที่เราใช้เพื่อสนับสนุนธุรกิจของเรา และผู้ที่ผูกพันตามภาระผูกพันตามสัญญาในการเก็บรักษาข้อมูลส่วนบุคคลไว้เป็นความลับและใช้เฉพาะเพื่อวัตถุประสงค์ที่เราเปิดเผยแก่พวกเขาเท่านั้น

  • สำหรับการโอนกิจการ เราอาจแบ่งปันหรือโอนข้อมูลส่วนบุคคลของท่านเกี่ยวกับหรือในระหว่างการเจรจาการควบรวมกิจการ การขายทรัพย์สินของบริษัท การจัดหาเงินทุน หรือการเข้าซื้อกิจการทั้งหมดหรือบางส่วนของธุรกิจของเราให้แก่บริษัทอื่น

  • ในรูปแบบข้อมูลรวม เราอาจเปิดเผยข้อมูลรวมเกี่ยวกับผู้ใช้ของเรา และข้อมูลที่ไม่ระบุตัวบุคคลใด ๆ แก่พันธมิตรทางธุรกิจและบุคคลที่สามอื่น ๆ

  • เพื่อบังคับใช้ข้อกำหนดการใช้งานของเรา เราอาจเปิดเผยข้อมูลส่วนบุคคลของท่านเพื่อบังคับใช้และจัดการข้อตกลงสิทธิ์การใช้งานสำหรับผู้ใช้ปลายทางของเราและข้อตกลงอื่นใดที่เราได้ทำกับท่าน

  • เพื่อคุ้มครองสิทธิของเรา เราอาจเปิดเผยข้อมูลส่วนบุคคลของท่านเพื่อคุ้มครองสิทธิ ทรัพย์สิน หรือความปลอดภัยส่วนบุคคลของบริษัทของเรา พนักงาน สมาชิก และสมาชิกของสาธารณชน

  • เพื่อการปฏิบัติตามกฎหมาย เราอาจเปิดเผยข้อมูลส่วนบุคคลของท่านเพื่อปฏิบัติตามกฎหมายที่ใช้บังคับ คำสั่งศาล หรือกระบวนการทางกฎหมาย รวมถึงเพื่อตอบสนองต่อ: (ก) การแจ้งการละเมิดทรัพย์สินทางปัญญา (ข) การเรียกร้องว่าการกระทำของท่านหรือเนื้อหาที่ท่านอัปโหลดไปยัง Application ละเมิดสิทธิของบุคคลที่สาม (ค) คำขอของรัฐบาลหรือหน่วยงานกำกับดูแล และ/หรือ (ง) สอบสวนการใช้งานหรือตอบสนองต่อการละเมิดหรือการละเมิดเนื้อหาของบุคคลที่สามที่ถูกกล่าวหา

  • ด้วยความยินยอมของท่าน เราอาจเปิดเผยข้อมูลส่วนบุคคลของท่านเพื่อวัตถุประสงค์อื่นใดด้วยความยินยอมของท่าน

การรายงานการขัดข้องและการวินิจฉัย

เราใช้ Firebase Crashlytics และบริการ Firebase ที่เกี่ยวข้องซึ่ง Google จัดให้เพื่อช่วยให้เราตรวจสอบ วินิจฉัย บำรุงรักษา และปรับปรุงเสถียรภาพ ความปลอดภัย ฟังก์ชันการทำงาน และประสิทธิภาพของ Application เมื่อ Application ขัดข้อง พบข้อผิดพลาด หรือทำงานผิดปกติ บริการ Firebase อาจเก็บรวบรวมข้อมูลทางเทคนิค การวินิจฉัย และข้อมูลที่เกี่ยวกับอุปกรณ์บางอย่าง ซึ่งอาจรวมถึง:

  • ประเภทอุปกรณ์ รุ่นฮาร์ดแวร์ และเวอร์ชันระบบปฏิบัติการ

  • เวอร์ชันแอปพลิเคชัน สภาพแวดล้อมรันไทม์ และข้อมูลการกำหนดค่า

  • บันทึกการขัดข้อง สแต็กเทรซ และรายงานการวินิจฉัย

  • การประทับเวลา สถานะเซสชัน และข้อมูลทางเทคนิคที่เกี่ยวกับเหตุการณ์

  • ตัวระบุอุปกรณ์ ตัวระบุการติดตั้ง Firebase หรือตัวระบุทางเทคนิคที่คล้ายคลึงกัน และ

  • การวินิจฉัยประสิทธิภาพ เสถียรภาพ และการใช้งานที่เกี่ยวกับ Application

เราใช้ข้อมูลนี้เพื่อระบุและแก้ไขข้อบกพร่อง ปรับปรุงประสิทธิภาพและความน่าเชื่อถือ วินิจฉัยปัญหาทางเทคนิค รักษาความเข้ากันได้ และปรับปรุงการดำเนินงานโดยรวมของ Application

แม้ว่าโดยทั่วไปข้อมูลนี้จะไม่ระบุตัวท่านโดยตรงด้วยชื่อ ที่อยู่อีเมล หรือตัวระบุโดยตรงที่คล้ายคลึงกัน แต่ข้อมูลบางอย่างที่เก็บรวบรวมผ่านบริการเหล่านี้อาจถือเป็นข้อมูลส่วนบุคคลภายใต้กฎหมายที่ใช้บังคับ

บริการ Firebase ที่ใช้เกี่ยวกับ Application ดำเนินการโดย Google และอยู่ภายใต้นโยบายความเป็นส่วนตัวของ Google และข้อกำหนดในการให้บริการ Firebase ที่ใช้บังคับ เราไม่ได้ใช้ Firebase Crashlytics เพื่อติดตามพฤติกรรมของท่านในแอปพลิเคชันต่าง ๆ หรือเพื่อวัตถุประสงค์ทางการตลาด Crashlytics เก็บรวบรวมหรือได้มาซึ่งคุณลักษณะบางอย่าง ตามที่อธิบายไว้ที่นี่

ขึ้นอยู่กับอุปกรณ์ ระบบปฏิบัติการ ภูมิภาค หรือการตั้งค่า Application ของท่าน ท่านอาจสามารถจำกัดฟังก์ชันการวิเคราะห์ การวินิจฉัย หรือการรายงานการขัดข้องบางอย่างได้ผ่านการตั้งค่าอุปกรณ์หรือการตั้งค่า Application ของท่านในกรณีที่มีการควบคุมดังกล่าว

การจัดเก็บข้อมูลบนคลาวด์และส่วนประกอบที่ดาวน์โหลดได้

Application อาจใช้บริการการจัดเก็บข้อมูลบนคลาวด์ การโฮสต์ การจัดส่งเนื้อหา หรือการกระจายไฟล์ รวมถึงบริการที่จัดให้ผ่าน Firebase หรือผู้ให้บริการบุคคลที่สามอื่น ๆ เพื่อส่งมอบส่วนประกอบที่ดาวน์โหลดได้ ทรัพยากรภาษา โมดูลคุณลักษณะ ไฟล์การกำหนดค่า การอัปเดต หรือฟังก์ชัน Application ที่เกี่ยวข้องไปยังอุปกรณ์ของท่าน เมื่อ Application เข้าถึงบริการเหล่านี้ ผู้ให้บริการบุคคลที่สามอาจได้รับข้อมูลทางเทคนิค การวินิจฉัย หรือข้อมูลที่เกี่ยวกับคำขอที่จำกัด ซึ่งอาจรวมถึง:

  • ข้อมูลเมตาของอุปกรณ์และแอปพลิเคชัน

  • ตัวระบุการติดตั้งหรือตัวระบุทางเทคนิคที่คล้ายคลึงกัน

  • บันทึกคำขอและกิจกรรมการดาวน์โหลด

  • ข้อมูลเครือข่ายและการเชื่อมต่อ และ

  • ข้อมูลทางเทคนิคที่จำเป็นในการอำนวยความสะดวกในการส่งมอบทรัพยากร Application อย่างปลอดภัยและมีประสิทธิภาพ

เราใช้บริการเหล่านี้เพื่อจัดหา บำรุงรักษา เพิ่มประสิทธิภาพ รักษาความปลอดภัย อัปเดต และปรับปรุง Application และฟังก์ชันที่เกี่ยวข้อง โดยทั่วไปเราไม่ได้เชื่อมโยงกิจกรรมคำขอการจัดเก็บข้อมูลบนคลาวด์กับตัวตนโดยตรงของท่าน และเราไม่ได้ใช้บริการเหล่านี้เพื่อการโฆษณาตามพฤติกรรมหรือการสร้างโปรไฟล์การโฆษณาข้ามแพลตฟอร์มโดยเจตนา

การซื้อคุณลักษณะแบบชำระเงิน การสมัครสมาชิก บัตรผ่าน การปลดล็อกตลอดชีพ หรือฟังก์ชันที่สร้างรายได้อื่น ๆ ที่เสนอผ่าน Application จะได้รับการประมวลผลผ่านผู้จัดจำหน่ายแอปหรือผู้ให้บริการชำระเงินที่ใช้บังคับ รวมถึงแต่ไม่จำกัดเพียง Apple, Google หรือระบบการชำระเงินและการเรียกเก็บเงินของแต่ละราย เมื่อท่านเริ่มการซื้อ ผู้จัดจำหน่ายแอปหรือผู้ให้บริการชำระเงินที่ใช้บังคับจะประมวลผลธุรกรรมโดยตรง เราไม่ได้เก็บรวบรวม ประมวลผล จัดเก็บ หรือเข้าถึงข้อมูลบัตรชำระเงินที่สมบูรณ์ของท่านหรือรายละเอียดการเรียกเก็บเงินทั้งหมดที่ใช้ในการทำธุรกรรมดังกล่าว ผู้จัดจำหน่ายแอป ผู้ให้บริการชำระเงิน และบริการบุคคลที่สามที่เกี่ยวข้องอาจเก็บรวบรวมและประมวลผลข้อมูลบางอย่างเกี่ยวกับการซื้อและการสมัครสมาชิก รวมถึง:

  • ตัวระบุบัญชี

  • ตัวระบุอุปกรณ์

  • ประวัติธุรกรรม

  • สถานะการสมัครสมาชิก

  • การยืนยันการซื้อ

  • ข้อมูลที่เกี่ยวกับภูมิภาคหรือภาษี และ

  • ข้อมูลการเรียกเก็บเงินหรือธุรกรรมทางเทคนิคที่เกี่ยวข้อง

เราอาจได้รับข้อมูลที่เกี่ยวกับธุรกรรมที่จำกัดจากผู้จัดจำหน่ายแอป ผู้ให้บริการชำระเงิน RevenueCat หรือผู้ให้บริการที่เกี่ยวข้อง เช่น สถานะการสมัครสมาชิก สถานะสิทธิ์ สถานะการต่ออายุ สถานะการยกเลิก ตัวระบุผลิตภัณฑ์ และการยืนยันการซื้อ เราใช้ข้อมูลนี้เพียงเพื่อจัดหา จัดการ บำรุงรักษา รักษาความปลอดภัย สนับสนุน และตรวจสอบการเข้าถึงคุณลักษณะแบบชำระเงินและฟังก์ชันที่เกี่ยวข้องเท่านั้น

การซื้อ การเรียกเก็บเงิน การสมัครสมาชิก การต่ออายุ การยกเลิก การคืนเงิน ความพร้อมใช้งานของการแชร์กับครอบครัว และฟังก์ชันการชำระเงินที่เกี่ยวข้องยังอยู่ภายใต้ข้อกำหนด เงื่อนไข และนโยบายความเป็นส่วนตัวของผู้จัดจำหน่ายแอปหรือผู้ให้บริการชำระเงินที่ใช้บังคับด้วย

การโฆษณา

บางส่วนของ Application รวมถึงฟังก์ชันการเข้าถึงแบบฟรีบางอย่าง อาจแสดงโฆษณา เนื้อหาที่ได้รับการสนับสนุน เนื้อหาส่งเสริมการขาย หรือฟังก์ชันที่ได้รับการสนับสนุนจากการโฆษณาอื่น ๆ โฆษณาหรือเนื้อหาส่งเสริมการขายดังกล่าวอาจส่งโดยผู้ให้บริการด้านการโฆษณา การสร้างรายได้ การวิเคราะห์ หรือการไกล่เกลี่ยของบุคคลที่สาม

ผู้ให้บริการบุคคลที่สามของเราอาจใช้ตัวระบุอุปกรณ์ ตัวระบุการโฆษณา ที่อยู่ IP ภูมิภาคทางภูมิศาสตร์โดยประมาณ ข้อมูลการใช้งาน หรือข้อมูลทางเทคนิคที่จำกัดอื่น ๆ เพื่อส่ง วัดผล จัดการ สนับสนุน จำกัด ปรับให้เหมาะกับบุคคล หรือปรับปรุงการโฆษณา การสร้างรายได้ การวิเคราะห์ หรือฟังก์ชัน Application ที่เกี่ยวข้อง

ขึ้นอยู่กับการตั้งค่าอุปกรณ์ ภูมิภาค สิทธิ์ของผู้จัดจำหน่ายแอป ตัวเลือกความยินยอม และกฎหมายที่ใช้บังคับของท่าน โฆษณาที่แสดงภายใน Application อาจเป็นแบบตามบริบท แบบไม่ปรับให้เหมาะกับบุคคล แบบปรับให้เหมาะกับบุคคล แบบตามความสนใจ หรือกำหนดค่าเป็นอย่างอื่นโดยผู้ให้บริการด้านการโฆษณาหรือแพลตฟอร์มที่ใช้บังคับ

เราไม่ได้ใช้เนื้อหาของผู้ใช้เพื่อการสร้างโปรไฟล์การโฆษณาตามพฤติกรรมข้ามแพลตฟอร์ม และเราไม่ได้ขายเนื้อหาของผู้ใช้ให้แก่บุคคลที่สามเพื่อวัตถุประสงค์ในการโฆษณา ผู้ให้บริการด้านการโฆษณาและการสร้างรายได้ของบุคคลที่สามอาจเก็บรวบรวม ประมวลผล รวม หรือใช้ข้อมูลตามนโยบายความเป็นส่วนตัว ข้อกำหนด และแนวปฏิบัติของตนเอง เราไม่ควบคุมแนวปฏิบัติด้านความเป็นส่วนตัวหรือเทคโนโลยีของผู้ให้บริการด้านการโฆษณาของบุคคลที่สาม

ขึ้นอยู่กับอุปกรณ์ ระบบปฏิบัติการ ภูมิภาค หรือการตั้งค่าแพลตฟอร์มของท่าน ท่านอาจสามารถจำกัดการเก็บรวบรวมข้อมูลหรือการปรับให้เหมาะกับบุคคลที่เกี่ยวกับการโฆษณาบางอย่างได้ผ่านการตั้งค่าความเป็นส่วนตัวของอุปกรณ์ การตั้งค่าการโฆษณา การตั้งค่าความโปร่งใสในการติดตามแอป การควบคุมตัวระบุการโฆษณา หรือการควบคุมแพลตฟอร์มที่คล้ายคลึงกัน

การใช้คุกกี้ของบุคคลที่สาม

บางส่วนของ Application รวมถึงเนื้อหาของบุคคลที่สาม ฟังก์ชันการวิเคราะห์ ฟังก์ชันที่ได้รับการสนับสนุนจากการโฆษณา บริการการสร้างรายได้ ฟังก์ชันของผู้จัดจำหน่ายแอป หรือบริการของบุคคลที่สามที่รวมเข้าด้วยกัน อาจใช้คุกกี้ พิกเซล เว็บบีคอน SDK ตัวระบุอุปกรณ์ พื้นที่จัดเก็บภายในเครื่อง ตัวระบุการโฆษณา หรือเทคโนโลยีที่คล้ายคลึงกันเพื่อเก็บรวบรวมข้อมูลทางเทคนิค การใช้งาน การวินิจฉัย หรือข้อมูลที่เกี่ยวกับอุปกรณ์ที่เกี่ยวกับการใช้งาน Application ของท่าน

เมื่อท่านใช้งาน Application โดยทั่วไปบุคคลที่สามจะใช้ SDK บนมือถือ ตัวระบุอุปกรณ์ ตัวระบุการโฆษณา พื้นที่จัดเก็บภายในเครื่อง หรือเทคโนโลยีมือถือที่คล้ายคลึงกันมากกว่าคุกกี้เบราว์เซอร์แบบดั้งเดิม ขึ้นอยู่กับ Application การตั้งค่าอุปกรณ์ของท่าน ภูมิภาคของท่าน ตัวเลือกความยินยอมของท่าน กฎหมายที่ใช้บังคับ และการกำหนดค่าบริการของบุคคลที่สาม เทคโนโลยีเหล่านี้อาจถูกใช้เพื่อ:

  • จัดหา ดำเนินการ บำรุงรักษา รักษาความปลอดภัย และปรับปรุง Application

  • วัดผลประสิทธิภาพ การมีส่วนร่วม และการวิเคราะห์

  • สนับสนุนฟังก์ชันการสร้างรายได้หรือการโฆษณา

  • จำกัดการฉ้อโกง การใช้ในทางที่ผิด หรือกิจกรรมที่ไม่ได้รับอนุญาต

  • ปรับให้เหมาะกับบุคคลหรือเพิ่มประสิทธิภาพเนื้อหาหรือฟังก์ชันบางอย่าง และ

  • สนับสนุนฟังก์ชันของผู้จัดจำหน่ายแอป การวิเคราะห์ การโฆษณา หรือที่เกี่ยวกับการสมัครสมาชิก

ผู้ให้บริการบุคคลที่สามอาจเก็บรวบรวม ประมวลผล รวม เชื่อมโยง หรือใช้ข้อมูลตามนโยบายความเป็นส่วนตัว ข้อกำหนด และแนวปฏิบัติของตนเอง เราไม่ควบคุมแนวปฏิบัติด้านความเป็นส่วนตัวหรือเทคโนโลยีที่ผู้ให้บริการบุคคลที่สามใช้ ขึ้นอยู่กับเบราว์เซอร์ อุปกรณ์ ระบบปฏิบัติการ ภูมิภาค หรือการตั้งค่าแพลตฟอร์มของท่าน ท่านอาจสามารถควบคุมคุกกี้ เทคโนโลยีการติดตาม การวิเคราะห์ ตัวระบุการโฆษณา หรือการตั้งค่าการปรับให้เหมาะกับบุคคลบางอย่างได้ผ่านการตั้งค่าเบราว์เซอร์ การตั้งค่าอุปกรณ์ การตั้งค่าความโปร่งใสในการติดตามแอป การตั้งค่าการโฆษณา/ความเป็นส่วนตัว หรือการควบคุมแพลตฟอร์มที่คล้ายคลึงกัน

สำหรับข้อมูลเพิ่มเติมเกี่ยวกับการควบคุมที่เกี่ยวกับการโฆษณา ท่านอาจทบทวนการตั้งค่าความเป็นส่วนตัวและการโฆษณาที่จัดให้โดยผู้ผลิตอุปกรณ์ ผู้ให้บริการระบบปฏิบัติการ ผู้ให้บริการเบราว์เซอร์ หรือผู้จัดจำหน่ายแอปของท่าน

4. วิธีที่เรารักษาความปลอดภัยข้อมูลส่วนบุคคลของท่าน

Application อาจมี รวมเข้ากับ เข้าถึง แสดง หรือให้ลิงก์ไปยังเนื้อหาของบุคคลที่สาม (ตามที่นิยามไว้ในข้อตกลงสิทธิ์การใช้งานสำหรับผู้ใช้ปลายทางที่ใช้บังคับ) รวมถึงแต่ไม่จำกัดเพียง เว็บไซต์ แอปพลิเคชัน SDK API ผู้จัดจำหน่ายแอป ผู้ให้บริการด้านการวิเคราะห์ ผู้ให้บริการด้านการโฆษณา ผู้ให้บริการชำระเงิน บริการคลาวด์ ผู้ให้บริการด้านการสร้างรายได้ของบุคคลที่สาม หรือฟังก์ชันหรือบริการของบุคคลที่สามอื่น ๆ (เรียกรวมกันว่า "Third-Party Services") นโยบายความเป็นส่วนตัวนี้ไม่ใช้กับแนวปฏิบัติด้านความเป็นส่วนตัว ความปลอดภัย การเก็บรวบรวมข้อมูล หรือการจัดการข้อมูลของ Third-Party Services เว้นแต่ตามที่อธิบายไว้อย่างชัดแจ้งในนโยบายความเป็นส่วนตัวนี้ ผู้ให้บริการบุคคลที่สามอาจเก็บรวบรวม ประมวลผล จัดเก็บ ใช้ เปิดเผย รวม หรือโอนข้อมูลอย่างเป็นอิสระตามนโยบายความเป็นส่วนตัว ข้อกำหนด และแนวปฏิบัติของตนเอง

California Consumer Privacy Act ("CCPA")

หากการประมวลผลข้อมูลส่วนบุคคลของท่านอยู่ภายใต้ CCPA ท่านมีสิทธิที่จะ:

  • ขอให้เราเปิดเผยหมวดหมู่และชิ้นส่วนเฉพาะของข้อมูลส่วนบุคคลที่เราเก็บรวบรวม ใช้ เปิดเผย และขาย

  • ทราบหมวดหมู่ของข้อมูลส่วนบุคคลที่เราเก็บรวบรวมและวัตถุประสงค์ที่เราเก็บรวบรวมหรือใช้ข้อมูลส่วนบุคคลดังกล่าว และว่าข้อมูลนั้นถูกขายหรือแบ่งปันหรือไม่

  • ทราบหมวดหมู่ของแหล่งที่มาที่เก็บรวบรวมข้อมูลส่วนบุคคล

  • ทราบหมวดหมู่ของบุคคลที่สามที่เราแบ่งปันหรือขายข้อมูลส่วนบุคคลของท่านให้

  • ทราบว่าเราเก็บรวบรวมหรือขายข้อมูลส่วนบุคคลของท่านเพื่อวัตถุประสงค์ทางธุรกิจหรือเชิงพาณิชย์หรือไม่

เว็บเบราว์เซอร์และอุปกรณ์บางอย่างอาจมีการตั้งค่าหรือคุณลักษณะความเป็นส่วนตัว เช่น "Do Not Track" (DNT), Global Privacy Control (GPC), App Tracking Transparency (ATT), การควบคุมตัวระบุการโฆษณา หรือกลไกการกำหนดความชอบด้านความเป็นส่วนตัวที่คล้ายคลึงกัน

  • วัตถุประสงค์เพื่อประโยชน์สาธารณะในกรณีที่ใช้บังคับ และ

  • ผลประโยชน์อันชอบด้วยกฎหมายของเรา รวมถึงผลประโยชน์ที่เกี่ยวกับการดำเนินการ การรักษาความปลอดภัย การบำรุงรักษา การปรับปรุง การสร้างรายได้ การสนับสนุน การวิเคราะห์ การจัดจำหน่าย การคุ้มครอง หรือการพัฒนา Application โดยมีเงื่อนไขว่าผลประโยชน์ดังกล่าวไม่ถูกแทนที่ด้วยสิทธิและเสรีภาพของท่าน

เรายังอาจประมวลผลข้อมูลส่วนบุคคลตามที่จำเป็นอย่างสมเหตุสมผลเพื่อ:

  • ให้การสนับสนุนลูกค้า

  • จัดการการสมัครสมาชิก การซื้อ และฟังก์ชันการสร้างรายได้

  • ตรวจจับการฉ้อโกง การใช้ในทางที่ผิด เหตุการณ์ด้านความปลอดภัย หรือกิจกรรมที่ไม่ได้รับอนุญาต

  • บังคับใช้ข้อตกลง นโยบาย หรือสิทธิทางกฎหมาย

  • ปฏิบัติตามภาระผูกพันทางกฎหมายหรือกฎเกณฑ์ และ

  • รักษาฟังก์ชันการทำงาน ความสมบูรณ์ ประสิทธิภาพ และความปลอดภัยของ Application

การที่ท่านเข้าถึงหรือใช้งาน Application ถือว่าท่านรับทราบว่ากิจกรรมการประมวลผลบางอย่างจำเป็นสำหรับเราในการจัดหา Application และปฏิบัติตามภาระผูกพันตามสัญญาของเราที่เกี่ยวกับ Application และบริการที่เกี่ยวข้อง

13. ภาคผนวกอเมริกาใต้และละตินอเมริกา

บุคคลที่อยู่ในอเมริกาใต้ ละตินอเมริกา อเมริกากลาง หรือเขตอำนาจศาลอื่น ๆ ที่มีกฎหมายความเป็นส่วนตัวหรือการคุ้มครองข้อมูลที่ใช้บังคับ อาจมีสิทธิเพิ่มเติมเกี่ยวกับข้อมูลส่วนบุคคลของพวกเขาภายใต้กฎหมายที่ใช้บังคับ รวมถึงแต่ไม่จำกัดเพียง Lei Geral de Proteção de Dados (LGPD) ของบราซิล, Ley de Protección de los Datos Personales (Law No. 25.326) ของอาร์เจนตินา และกรอบความเป็นส่วนตัวหรือการคุ้มครองข้อมูลที่คล้ายคลึงกัน

สำหรับวัตถุประสงค์ของส่วนนี้ "ข้อมูลส่วนบุคคล" โดยทั่วไปหมายถึงข้อมูลที่เกี่ยวกับบุคคลธรรมดาที่ระบุตัวตนได้หรือสามารถระบุตัวตนได้ และอาจรวมถึงข้อมูลการติดต่อ ตัวระบุอุปกรณ์ ข้อมูลทางเทคนิค ข้อมูลการใช้งาน ข้อมูลที่เกี่ยวกับการสนับสนุน หรือข้อมูลอื่น ๆ ที่อธิบายไว้ในนโยบายความเป็นส่วนตัวนี้

ขึ้นอยู่กับเขตอำนาจศาลและกฎหมายที่ใช้บังคับของท่าน ท่านอาจมีสิทธิบางอย่างที่เกี่ยวกับข้อมูลส่วนบุคคลของท่าน รวมถึงสิทธิที่จะ:

  • ยืนยันว่าเราประมวลผลข้อมูลส่วนบุคคลของท่านหรือไม่

  • ขอเข้าถึงข้อมูลส่วนบุคคลที่เราเก็บรักษาเกี่ยวกับท่าน

  • ขอแก้ไขข้อมูลส่วนบุคคลที่ไม่ถูกต้อง ล้าสมัย หรือไม่สมบูรณ์

  • ขอลบ ทำให้ไม่ระบุตัวตน หรือบล็อกข้อมูลส่วนบุคคลบางอย่าง

  • ขอความสามารถในการเคลื่อนย้ายข้อมูลส่วนบุคคลบางอย่าง

  • คัดค้านหรือขอจำกัดกิจกรรมการประมวลผลบางอย่าง

  • ถอนความยินยอมในกรณีที่การประมวลผลเป็นไปตามความยินยอม

  • ขอข้อมูลเกี่ยวกับแนวปฏิบัติการประมวลผลข้อมูลและการเปิดเผยต่อบุคคลที่สามของเรา และ

  • ยื่นข้อร้องเรียนต่อหน่วยงานคุ้มครองข้อมูลหรือหน่วยงานกำกับดูแลที่ใช้บังคับของท่าน

เนื่องจากฟังก์ชันที่เกี่ยวกับการแปลหลักโดยทั่วไปจะประมวลผลภายในเครื่องบนอุปกรณ์ของท่าน เนื้อหาของผู้ใช้และข้อมูลที่เกี่ยวข้องบางอย่างอาจยังคงจัดเก็บไว้บนอุปกรณ์ของท่านเท่านั้นและอาจไม่สามารถเข้าถึงได้สำหรับเรา ในการใช้สิทธิความเป็นส่วนตัวของท่าน โปรดติดต่อเราโดยใช้ข้อมูลการติดต่อที่ให้ไว้ในนโยบายความเป็นส่วนตัวนี้ เราอาจขอข้อมูลที่จำเป็นในการตรวจสอบตัวตนของท่านก่อนตอบสนองต่อคำขอของท่าน ตามที่กฎหมายที่ใช้บังคับอนุญาต สิทธิบางอย่างอาจถูกจำกัดหรืออยู่ภายใต้ข้อยกเว้นตามกฎหมายที่ใช้บังคับ เราจะตอบสนองต่อคำขอที่ตรวจสอบแล้วภายในกรอบเวลาที่กฎหมายที่ใช้บังคับกำหนด

14. ภาคผนวกยูเครน

หากท่านอยู่ในยูเครน เราประมวลผลข้อมูลส่วนบุคคลตามกฎหมายของยูเครน "ว่าด้วยการคุ้มครองข้อมูลส่วนบุคคล" ฉบับที่ 2297-VI และกฎหมาย ข้อบังคับ หรือข้อกำหนดอื่น ๆ ที่ใช้บังคับที่เกี่ยวกับความเป็นส่วนตัว การคุ้มครองข้อมูล การสื่อสารทางอิเล็กทรอนิกส์ การคุ้มครองผู้บริโภค หรือความปลอดภัยทางไซเบอร์ ส่วนนี้เสริมข้อกำหนดอื่น ๆ ของนโยบายความเป็นส่วนตัวนี้และใช้บังคับโดยเฉพาะกับบุคคลที่อยู่ในยูเครน

สิทธิของท่าน

ภายใต้กฎหมายที่ใช้บังคับ ท่านอาจมีสิทธิบางอย่างเกี่ยวกับข้อมูลส่วนบุคคลของท่าน รวมถึงสิทธิที่จะ:

  • รับข้อมูลเกี่ยวกับการประมวลผลข้อมูลส่วนบุคคลของท่าน

  • ขอเข้าถึงข้อมูลส่วนบุคคลที่เราเก็บรักษาเกี่ยวกับท่าน

  • ขอแก้ไข อัปเดต จำกัด บล็อก หรือลบข้อมูลส่วนบุคคลบางอย่าง

  • คัดค้านกิจกรรมการประมวลผลบางอย่าง

  • ถอนความยินยอมในกรณีที่การประมวลผลเป็นไปตามความยินยอม และ

  • ยื่นข้อร้องเรียนต่อกรรมาธิการสิทธิมนุษยชนของรัฐสภายูเครน (ผู้ตรวจการแผ่นดิน) หรือหน่วยงานอื่นที่ใช้บังคับ

เนื่องจากฟังก์ชันที่เกี่ยวกับการแปลหลักโดยทั่วไปจะประมวลผลภายในเครื่องบนอุปกรณ์ของท่าน เนื้อหาของผู้ใช้และข้อมูลที่เกี่ยวข้องบางอย่างอาจยังคงจัดเก็บไว้บนอุปกรณ์ของท่านเท่านั้นและอาจไม่สามารถเข้าถึงได้สำหรับเรา

การโอนข้อมูลระหว่างประเทศ

Application อาจใช้ผู้ให้บริการ ผู้ให้บริการคลาวด์ ผู้ให้บริการด้านการวิเคราะห์ ผู้จัดจำหน่ายแอป ผู้ให้บริการด้านการโฆษณา ผู้ประมวลผลการชำระเงิน และผู้ให้บริการบุคคลที่สามอื่น ๆ ที่ประมวลผลข้อมูลในสหรัฐอเมริกาและประเทศอื่น ๆ นอกยูเครน ด้วยเหตุนี้ ข้อมูลส่วนบุคคลของท่านอาจถูกโอนไปยัง จัดเก็บใน เข้าถึงจาก หรือประมวลผลในเขตอำนาจศาลนอกยูเครนที่อาจไม่ได้ให้การคุ้มครองข้อมูลในระดับเดียวกันกับกฎหมายยูเครน

ในกรณีที่กฎหมายที่ใช้บังคับกำหนด เราจะดำเนินมาตรการที่สมเหตุสมผลในเชิงพาณิชย์และเหมาะสมซึ่งออกแบบมาเพื่อคุ้มครองข้อมูลส่วนบุคคลที่โอนข้ามเขตอำนาจศาล รวมถึงผ่านการคุ้มครองตามสัญญา มาตรการป้องกันด้านการปฏิบัติงาน มาตรการป้องกันด้านเทคนิค กลไกความยินยอมในกรณีที่กฎหมายอนุญาต หรือกลไกการโอนอื่น ๆ ที่ได้รับการยอมรับทางกฎหมาย

ฟังก์ชันที่เกี่ยวกับการแปลหลักโดยทั่วไปจะประมวลผลภายในเครื่องบนอุปกรณ์ของท่าน และเราไม่ได้โอนหรือจัดเก็บเนื้อหาของผู้ใช้บนเซิร์ฟเวอร์ของเรานอกยูเครนเพื่อวัตถุประสงค์ในการจัดหาฟังก์ชันการแปลหลัก อย่างไรก็ตาม ฟังก์ชันบางอย่างที่เกี่ยวกับการสนับสนุน การปฏิบัติงาน การวิเคราะห์ การสร้างรายได้ บนคลาวด์ หรือที่รวมกับบุคคลที่สาม อาจเกี่ยวข้องกับการส่งหรือการประมวลผลข้อมูลที่จำกัดตามที่อธิบายไว้ในนโยบายความเป็นส่วนตัวนี้

ความพร้อมใช้งานของ Application

การเข้าถึง Application อาจถูกขัดจังหวะ ล่าช้า เสื่อมประสิทธิภาพ ถูกจำกัด หรือไม่พร้อมใช้งานเนื่องจากสถานการณ์ที่อยู่นอกเหนือการควบคุมที่สมเหตุสมผลของเรา รวมถึงสงคราม ความขัดแย้งทางอาวุธ เหตุการณ์ทางไซเบอร์ การกระทำของรัฐบาล การคว่ำบาตร อินเทอร์เน็ตขัดข้อง การหยุดชะงักของโครงสร้างพื้นฐาน ไฟฟ้าดับ ความล้มเหลวของระบบโทรคมนาคม หรือเหตุการณ์ที่เกี่ยวข้องที่ส่งผลกระทบต่อยูเครนหรือภูมิภาคอื่น ๆ เราไม่รับผิดชอบต่อการขัดจังหวะ ความล่าช้า การสูญเสียฟังก์ชันการทำงาน หรือความไม่พร้อมใช้งานที่เป็นผลมาจากสถานการณ์ดังกล่าว หากท่านมีคำถามเกี่ยวกับภาคผนวกสิทธิความเป็นส่วนตัวยูเครนนี้ หรือประสงค์จะใช้สิทธิของท่านภายใต้กฎหมายที่ใช้บังคับ โปรดติดต่อเราโดยใช้ข้อมูลการติดต่อที่ให้ไว้ในนโยบายความเป็นส่วนตัวนี้
