Frequently Asked Questions

If you are experiencing freezing or hanging, please follow these steps: Completely remove the app. Install the latest version from the app store. Ensure that your device has enough storage space. Close other applications and try reopening Lingofonex. We are also continuously working to improve performance in upcoming updates.
For a quick guide on how to use the app, visit our User Demo page. It provides simple instructions to help you get started. Quick tips: when ready to speak, press the input language button and speak immediately; use shorter sentences for the best results.
Lingofonex downloads offline models to support translation features, which can take up space. The display of the downloading process may lag behind, so it could appear that the download is still happening even though the files have already been fully transferred. We're working to improve the transparency of this process. We recommend removing the app and reinstalling the latest version if you are having issues with starting the app.
In case the app doesn't start after downloading the models, please remove the app completely, download the latest version, and try loading the models again.
Downloading the initial translation models requires a large amount of data. To avoid using up mobile data and to ensure faster downloads, we recommend using WiFi during the first installation and setup.
We are continuously improving Lingofonex based on user feedback and plan to add new features over time. Stay tuned for updates!
If you encounter any issues or need further assistance, please use our Contact Form, and our support team will respond as soon as possible.
