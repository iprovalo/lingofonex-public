Perguntas frequentes

Se o aplicativo estiver travando ou não respondendo, siga estas etapas: remova completamente o aplicativo, instale a versão mais recente da loja de aplicativos, verifique se o dispositivo tem espaço de armazenamento suficiente, feche outros aplicativos e tente reabrir o Lingofonex. Também estamos trabalhando continuamente para melhorar o desempenho nas próximas atualizações.
Para um guia rápido sobre como usar o aplicativo, visite nossa página de Demonstração. Ela fornece instruções simples para ajudá-lo a começar. Dicas rápidas: quando estiver pronto para falar, pressione o botão do idioma de entrada e fale imediatamente; use frases curtas para obter os melhores resultados.
O Lingofonex baixa modelos offline para suportar recursos de tradução, que podem ocupar espaço. A exibição do processo de download pode estar atrasada, então pode parecer que o download ainda está em andamento mesmo que os arquivos já tenham sido totalmente transferidos. Estamos trabalhando para melhorar a transparência deste processo. Recomendamos remover o aplicativo e reinstalar a versão mais recente se você estiver tendo problemas para iniciar o aplicativo.
Caso o aplicativo não inicie após o download dos modelos, remova o aplicativo completamente, baixe a versão mais recente e tente carregar os modelos novamente.
O download dos modelos de tradução iniciais requer uma grande quantidade de dados. Para evitar o consumo de dados móveis e garantir downloads mais rápidos, recomendamos o uso de WiFi durante a primeira instalação e configuração.
Estamos melhorando continuamente o Lingofonex com base no feedback dos usuários e planejamos adicionar novos recursos ao longo do tempo. Fique atento às atualizações!
Se você encontrar algum problema ou precisar de mais assistência, use nosso formulário de contato e nossa equipe de suporte responderá o mais rápido possível.
