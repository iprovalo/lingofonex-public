# Pakt SEO Landing Component Library

This folder contains the reusable landing-page component inventory for Pakt SEO pages.

Read the full source brief first:

- `pakt_seo_landing_component_library_for_agent.md`

Then use these quick references:

- `block-inventory.md`
- `block-options.md`

## Implementation Rule

Implement only reusable landing-page blocks that are visibly present in the approved Pakt design files. Copy must stay configurable per page. Components should assemble `/pakt/` and future `/pakt/*` SEO pages from data/config, not hardcoded page-specific text.

## Explicitly Out Of Scope

These were not clearly present as reusable SEO landing-page components. Do not implement them unless separately requested:

- Sticky mobile CTA bar
- Breadcrumb visual block
- Press/reviews/logo strip
- Pricing/paywall landing-page block
- Camera/OCR marketing block
- Blog-card/feed block
- Testimonial carousel
- Case-study block
