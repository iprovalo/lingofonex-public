Pakt en mode avion

Pakt fonctionne-t-il en mode avion ?

Oui. Téléchargez vos langues avant le voyage, puis Pakt pourra les traduire sur votre téléphone sans connexion réseau.

Que dois-je télécharger avant d’utiliser Pakt hors ligne ?

Téléchargez la langue que vous utilisez et la langue parlée à votre destination avant le voyage.

Pakt peut-il traduire sans WiFi ni données mobiles ?

Oui. Pakt traduit les langues téléchargées sur votre téléphone sans WiFi ni données mobiles.

Pakt peut-il lire les traductions en mode avion ?

Oui, dans 50 langues prises en charge. Pakt traduit dans 100 langues, la lecture à voix haute n'est donc pas disponible pour toutes les langues.

Comment tester Pakt avant un voyage ?

Activez le mode avion et essayez une phrase dans les deux sens avant de partir.

Pakt envoie-t-il des traductions hors ligne vers le cloud ?

Non. Une fois les langues téléchargées, Pakt peut les traduire sur votre téléphone sans envoyer chaque phrase à un service de traduction cloud.
